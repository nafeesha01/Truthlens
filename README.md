# TruthLens

TruthLens is a machine-learning-powered news credibility assessment platform that analyzes textual patterns in news articles and estimates whether content resembles real or fake news examples.

## Features

- News credibility assessment
- TF-IDF vectorization
- Logistic Regression classifier
- Confidence score visualization
- Analysis history
- Explainability insights
- Responsive UI

## Tech Stack

### Frontend

- React
- Vite
- CSS

### Backend

- Flask
- Flask-CORS

### Machine Learning

- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression

## Dataset

- Fake.csv
- True.csv

## Model Performance

- Accuracy: 98.88%

## Installation

### Backend

```bash
pip install -r requirements.txt
python app.py
```

### Frontend

